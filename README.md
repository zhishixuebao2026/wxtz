## 维护手册（以后一切修改与更新都只在本文件夹内）

1. 加词条：编辑 `data/lexicon.js`，往 `WXLEXICON` 数组末尾加 `{ t, p, cat, d }`；
   cat 用已有分类（法则/地理/公门/众生/术法/器物/悬疑）。
2. 加异闻：编辑 `data/stories.js`，往 `WXSTORIES` 末尾加
   `{ id, no, title, sub, paras: [ ...段... ], tail: 尾注 }`。
3. 加人物：编辑 `data/characters.js`，往 `WXCHARS` 末尾加
   `{ id, name, title, place, cat, temper, text, hook, origin }`，
   cat 用已有六类（塔主/公门/修士/异物/邪路/异闻）。
4. 加城市或改坐标：编辑 `data/cities.js`；改 `pos` 即可在账图上挪位置。
   但 `pos` 或 `roads[].r` 一改，`roads[].li`（道里）就与图不符，须按弧长重算：
   弧长 ÷ 2.5（一里 = 二点五格）÷ 10 取整 × 10。渡金沟之道必须走三桥，不得斜穿。
5. 改任何设定文案：直接改对应 `data/*.js` 的字符串，刷新页面即生效。
6. 新增一整篇：`index.html` 加 `<section class="page">` + 导航按钮 `data-goto`；
   渲染逻辑加在 `assets/app.js`；`PAGES` 数组记得加名字；新增数据文件记得在 `tools/audit.js` 顶部 DATA 清单补列文件名。
7. 每次改动后，在 `data/updates.js` 的 `WXUPDATES` 最前面记一条版本。
8. 铁律：`D:\BaiduNetdiskDownload`、`D:\备份` 及本文件夹之外的任何文件，
    一律不动；素材与源文件只读。
9. 字体与部署：霞鹜文楷 Lite 的常用字形子集已自托管，许可全文随字体资源分发；
    首页背景图亦为本地原创资源。页面运行不请求第三方字体或图片服务，离线打开仍可读。
    字体依 SIL Open Font License 1.1 分发；随附的样式表依其 MIT 许可，改作与再分发时保留对应许可文本。
10. 账面净言（用户明规）：更新志与溯源簿只用世界内语言，不提本站文件路径、
    文件名、工具与代码名目（审计第十六科把守）；本地素材出处一律以
    「私域素材《…》」声明——来路要真，路径不上账面。
11. 加试账：编辑 `data/trials.js` 中的 `WXTRIALS`，每案须明确贷方、借方、余账、
    判语与复核依据；增加案例时同步检验城市引用，并将题名与正文纳入全书索引。
12. 加仓制：编辑 `data/granaries.js` 中的 `WXGRANARIES`；三仓职责不得互相吞账，
    每种仓事须同时交代实物去向、票据与复核点；网络参照记入溯源簿，文案保持原创。
13. 添人物画像：在人物资料中可为指定人物登记随站画像；优先用 WebP 并提供替代文字，原图保持同一套乌金朱印画风。
